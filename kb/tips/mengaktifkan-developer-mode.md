# Mengaktifkan "Developer Mode"

### Deskripsi

Beberapa tips di sini membutuhkan akses ke User ID, Role ID, dan Channel ID. Tapi, ID tersebut tidak langsung tersedia oleh karena hanya muncul ketika kita mengaktifkan Developer Mode di Discord.

Berikut adalah cara mudah untuk mengaktifkan Developer Mode di aplikasi Discord Desktop, Browser, dan Mobile (hp).

### Versi Desktop / Browser

{% stepper %}
{% step %}
### Buka "User Settings"

<figure><img src="../../.gitbook/assets/{7BDFD260-D4CE-4988-A243-4BDA59675901}.png" alt=""><figcaption><p>Letak "User Settings"</p></figcaption></figure>
{% endstep %}

{% step %}
### Aktifkan "Developer Mode"

Di kotak "Search" ketik "developer", klik "Advanced", dan aktifkan "Developer Mode".

<figure><img src="../../.gitbook/assets/tips-0000-0002.jpg" alt="" width="563"><figcaption><p>Mengaktifkan "Developer Mode"</p></figcaption></figure>

Setelah Developer Mode diaktifkan, maka menu seperti Copy User ID, Copy Role ID, dan Copy Channel ID akan tersedia di menu pop-up masing-masing.
{% endstep %}
{% endstepper %}

### Versi Mobile

{% stepper %}
{% step %}
### Buka "Settings"

Tekan ikon profilmu di kanan bawah, setelah profilmu muncul, tekan ikon gir di kanan atas.

<figure><img src="../../.gitbook/assets/tips-0003-0002.jpg" alt="" width="563"><figcaption><p>Letak tombol "Settings"</p></figcaption></figure>
{% endstep %}

{% step %}
### Buka menu "Advanced"

Di kotak "Search" ketik "developer", tekan "Developer Mode (Advanced)"

<figure><img src="../../.gitbook/assets/tips-0003-0000.jpg" alt="" width="563"><figcaption><p>membuka menu "Advanced"</p></figcaption></figure>
{% endstep %}

{% step %}
### Aktifkan "Developer Mode"

Setelah halaman "Advanced" terbuka, aktifkan "Developer Mode"

<figure><img src="../../.gitbook/assets/tips-0003-0001.jpg" alt="" width="563"><figcaption><p>Mengaktifkan "Developer Mode"</p></figcaption></figure>

Setelah Developer Mode diaktifkan, maka menu seperti Copy User ID, Copy Role ID, dan Copy Channel ID akan tersedia di menu pop-up masing-masing.
{% endstep %}
{% endstepper %}

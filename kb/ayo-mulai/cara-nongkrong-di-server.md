# Cara 'nongkrong' di Server

<figure><img src="../../.gitbook/assets/kb-ayomulai-1-0.jpg" alt=""><figcaption><p>Channel Voice</p></figcaption></figure>

### **Melakukan Voicecall**

{% stepper %}
{% step %}
### Gabung ke Channel Voice !

* Klik salah satu Channel Voice yang ingin kamu gunakan.
{% endstep %}

{% step %}
### Mulai Ngobrol !

{% hint style="success" %}
Kamu akan melihat lingkaran hijau di sekitar gambar profilmu ketika Discord mendeteksi suaramu.
{% endhint %}

* Kalau kamu perlu mengubah pengaturan input voicenya, buka **User Settings** (ikon gir di kiri bawah). Di kotak **Search**, ketik **Voice Settings**, nanti akan muncul menu **Voice & Video**, klik menu itu, lalu halaman pengaturan **Voice & Video** bagian **Voice Settings** akan muncul.

<figure><img src="../../.gitbook/assets/kb-ayomulai-1-3.jpg" alt=""><figcaption><p>Pengaturan "Voice Settings" di menu "Voice &#x26; Video".</p></figcaption></figure>

{% hint style="success" %}
Kamu bisa mengatur volume dari masing-masing orang yang tergabung di Channel Voice, dengan mengklik kanan avatar orang tersebut.
{% endhint %}
{% endstep %}
{% endstepper %}

### Melakukan Videocall

<figure><img src="../../.gitbook/assets/kb-ayomulai-1-1.jpg" alt=""><figcaption><p>Contoh aktivitas Videocall.</p></figcaption></figure>

{% stepper %}
{% step %}
### Gabung ke Channel Voice !

* Klik salah satu Channel Voice yang ingin kamu gunakan.
{% endstep %}

{% step %}
### Bagikan Videomu !

* Tekan tombol "Turn On Camera" di kiri bawah.

<figure><img src="../../.gitbook/assets/kb-ayomulai-1-2.jpg" alt=""><figcaption><p>Tombol "Turn On Camera" untuk menggunakan input kamera.</p></figcaption></figure>

* Kalau kamu perlu mengubah pengaturan input videonya, buka **User Settings** (ikon gir di kiri bawah). Di kotak **Search**, ketik **Video Settings**, nanti akan muncul menu **Voice & Video**, klik menu itu, lalu halaman pengaturan **Voice & Video** bagian **Video Settings** akan muncul.

<figure><img src="../../.gitbook/assets/kb-ayomulai-1-4.jpg" alt=""><figcaption><p>Pengaturan "Video Settings" di menu "Voice &#x26; Video".</p></figcaption></figure>
{% endstep %}
{% endstepper %}

### Melakukan Sharescreen (membagikan tampilan perangkatmu)

{% stepper %}
{% step %}
### Gabung ke Channel Voice !

* Klik salah satu Channel Voice yang ingin kamu gunakan.
{% endstep %}

{% step %}
### Aktifkan screenshare !

* Tekan tombol "Share Your Screen" di kiri bawah.

<figure><img src="../../.gitbook/assets/kb-ayomulai-1-5.jpg" alt=""><figcaption><p>Tombol "Share Your Screen" untuk memilih tampilan.</p></figcaption></figure>
{% endstep %}

{% step %}
### Pilih jendela aplikasi atau layar untuk dibagikan

* Pilih jendela aplikasi apa, atau tampilan layar mana yang ingin kamu bagikan.

<figure><img src="../../.gitbook/assets/kb-ayomulai-1-6.jpg" alt=""><figcaption><p>Sembulan "Screen Share" untuk memilih jendela/layar/alat penangkap mana yang akan dibagikan.</p></figcaption></figure>
{% endstep %}

{% step %}
### Siarkan !

* Tekan tombol "Go Live" setelah memilih tampilan yang akan dibagikan, dan siap.

<figure><img src="../../.gitbook/assets/kb-ayomulai-1-7.jpg" alt=""><figcaption><p>Tombol "Go Live" untuk memulai siaran.</p></figcaption></figure>
{% endstep %}
{% endstepper %}

### Menonton Sharescreen (menonton tampilan yang dibagikan)

{% stepper %}
{% step %}
### Bergabung ke sebuah siaran

* Gabung ke Channel Voice berisi pengguna yang sedang membagikan tampilannya (ditandai dengan ikon "LIVE" berwarna merah).
{% endstep %}

{% step %}
### Tonton siarannya

* Sorot pengguna yang sedang siaran tersebut, lalu klik tombol "Watch Stream".

<figure><img src="../../.gitbook/assets/kb-ayomulai-1-8.jpg" alt=""><figcaption><p>Sembulan "Watch Stream" ketika pengguna yang sedang siaran tersorot kursor.</p></figcaption></figure>

Setelah bergabung, kamu bisa menyesuaikan tampilan dan suara dari siaran yang kamu tonton.
{% endstep %}
{% endstepper %}

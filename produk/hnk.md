# Harga & Ketentuan

<details>

<summary>Ketentuan Umum</summary>

K**etentuan ini berlaku di semua paket yang ada.**

1. <mark style="color:red;">**Vtucord tidak memfasilitasi VTuber yang menggunakan AI generatif, termasuk tapi tidak terbatas pada branding, konten, seni penggemar. Jika ditemukan pelanggaran, server akan dihapus permanen, VTuber terkait diblokir dari semua layanan kami, dan pelanggaran akan diumumkan secara terbuka di media sosial.**</mark>
2. Seluruh pembayaran adalah **SEKALI BAYAR** dan tidak ada **REFUND / PENGEMBALIAN DANA**.
3. Privasi VTuber dalam server selama masa manajemen dijamin aman.
4. Tidak meninggalkan server Vtucord 2.0.
5. Mengajukan **Buat/Ubah Server** dalam waktu 1x24 jam setelah bergabung.
6. Menjawab form **Buat/Ubah Server** yang telah diberikan selambat-lambatnya 1x24 jam setelah form diberikan.
7. **Buat/Ubah Server** sepenuhnya dibuat sesuai standar Vtucord 2.0.
8. Bersedia menerima dan mengingatkan member server untuk mengaktifkan verifikasi HP akun Discord.
9. Bersedia menerima crossposting-promotion dari partner Vtucord yang lainnya.
10. Bersedia server kami publikasikan untuk keperluan promosi.
11. Tim Vtucord hanya membuat/mengubah server dalam Bahasa Indonesia, dan tidak melayani lintas bahasa.
12. Tim Vtucord hanya mengizinkan permintaan bot/app tambahan yang sudah diverifikasi Discord, dan tim kami, serta sudah digunakan secara umum.
13. Segala pembatalan update server (membatalkan satu atau lebih update fitur server) akan mendowngrade dan mengecualikan server dari update di masa mendatang (**Buat Server**/**Buat Server Pro**).
14. Dilarang pindah **PAKET** selama masa manajemen.
15. Segala pelanggaran dan tindak kecurangan yang terjadi akan diumumkan ke seluruh server partner dan di sosial media, serta akan dilakukan penghapusan server secara permanen (Buat Server & Buat Server Pro), atau banned permanen (Ubah Server).\
    Hal ini termasuk tapi tidak terbatas pada:

* Menggunakan jasa ilegal untuk menambah anggota.
* Mencari dan memanfaatkan celah keamanan untuk mencuri akses ke server.
* Meninggalkan server tanpa sebab yang jelas.
* dan sejenisnya.

16. Informasi yang diberikan di tiket dianggap tidak valid jika disunting (ditandai dengan `(edited)` di riwayat obrolan). Balas/Reply informasi yang salah, dengan revisinya.
17. Ketentuan lain yang belum tertulis, akan disampaikan selanjutnya, menyesuaikan situasi dan kondisi yang ada.
18. Jika ada hal yang ingin ditanyakan seputar Vtucord 2.0, silahkan kunjungi [**Portal Bantuan kami**](https://portal.cimosoft.com/index.php?a=add\&category=2). Teliti sebelum bertanya, pastikan hal yang akan ditanyakan tidak ada di halaman web ini.

### Pembuatan/Request Server

Kami membuatkan server baru sesuai standar yang sudah kami buat sebelumnya.

Kami menyediakan 3 (tiga) Paket Pembuatan Server

<details>

<summary><strong>Buat Server VTuber Indie</strong></summary>

## **Rp0,00 (GRATIS)**

Server kami buat untuk personal VTuber Indie dengan masa manajemen 6 bulan / 180 hari, termasuk garansi dan pembaruan (jika ada).

#### Ketentuan

**VTuber calon pemilik server, selanjutnya disebut sebagai "kamu".**

1. Status VTuber adalah **Indie Aktif** sebelum mengajukan **Buat Server** dan tidak berubah atau melakukan **hiatus** selama masa manajemen.
2. Identitas VTuber tetap sama selama masa manajemen (Tidak melakukan rebranding dan/atau hal-hal yang berpotensi mengubah identitas utama server).
3. Status server adalah pribadi milik 1 VTuber (Bukan server komunitas/grup/berisi lebih dari satu VTuber dengan kedudukan yang sama.)
4. Masa manajemen termasuk garansi dan update adalah 6 bulan / 180 hari setelah server dibuat.
5. Kamu sudah memiliki channel streaming aktif (YouTube / Twitch) lebih dari 1 (satu) bulan dan akun sosial media, serta telah aktif menjadi VTuber.
6. Konfigurasi default Vtucord (channel, app, role) tidak dapat diubah selama masa manajemen.
7. Tanggung jawab Vtucord terbatas pada konfigurasi awal server, termasuk penyiapan app default serta pembuatan channel dan kategori sesuai standar serta sepengetahuan Vtucord.
8. Perubahan seperti mengubah atau mengurangi konfigurasi server yang telah disusun ulang (channel, app, role, default content, permission, dll...) tanpa sepengetahuan Tim Vtucord selama masa manajemen, akan membatalkan garansi dan bantuan manajemen akan dibatasi.
9. Server yang tidak aktif 30-60 hari akan ditangguhkan sementara, dan selebihnya akan dinonaktifkan.
10. **Tidak ada akses administrator** selama masa manajemen. Konsultasikan dengan Tim Vtucord terkait jika ingin melakukan perubahan.
11. Kepemilikan server akan diberikan setelah masa manajemen selesai.
12. Seluruh ketentuan tetap berlaku pada server yang melakukan pengajuan perpanjangan manajemen dan server dengan sistem kerjasama/partnership.

**Sudah siap memesan, atau masih ada yang ingin ditanyakan?** [**Tekan di sini**](hnk.md#sudah-siap-memesan)**.**

</details>
